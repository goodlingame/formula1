## 🎮 О игре

**F1 Racing — Cockpit Championship** — это аркадный симулятор гонок Formula 1, написанный на Python с использованием библиотеки Pygame. Игра предлагает уникальный опыт вождения от первого лица из кабины болида, с реалистичным рулём, зеркалами заднего вида, halo-дугой и полноценной 3D-проекцией трассы.

Игра сочетает в себе:
- 🏁 Аркадную физику с элементами симуляции
- 🗺️ 20 уникальных трасс со всего мира
- 👥 8 пилотов с индивидуальными характеристиками
- 🔧 Систему тюнинга и прокачки болида
- 💰 Экономику с наградами за призовые места

## ✨ Возможности

### 🏎️ Вид из кокпита
- **Реалистичный руль F1** с поворотом до 32° и экраном телеметрии
- **Halo-дуга** вокруг головы пилота
- **Зеркала заднего вида** с реальным отражением соперников сзади
- **Низкий нос болида** с характерными полосами
- **Покачивание камеры** от скорости и наклоны в поворотах

### 🛣️ Чёткая трасса
- Псевдо-3D рейкастинг по сегментам трассы
- Красные **кербы** с белыми вставками
- **Центральная разметка** с пунктиром
- **Туман** для плавного слияния дальних объектов с фоном
- Обрезка невидимых объектов (оптимизация)

### 🌍 Атмосфера
- **Дневные** и **ночные** трассы
- Градиентное небо
- Звёзды и луна на ночных трассах
- Уникальный фон для каждой трассы

### 🎯 Геймплей
- 8 AI-соперников с разными характеристиками
- Система чекпоинтов и подсчёт кругов
- Лучшее время круга
- Обратный отсчёт перед стартом
- Финишная таблица с наградами

## ⚙️ Технические детали

### Стек
- **Python 3.8+**
- **Pygame 2.0+**

### Разрешение
- **1280 × 720** (окно)
- **60 FPS** (ограничение)

### Размер мира
- **3000 × 2200** пикселей (мир трассы)

### Ключевые алгоритмы

#### Сплайн Катмулла-Рома
Трассы строятся на базе сплайна, что обеспечивает плавные повороты без изломов.

#### Рейкастинг по сегментам
Вид из кокпита использует проекцию сегментов трассы по нормалям:
- Вычисляются **нормали** каждой точки трассы
- Точки проецируются в экранные координаты через `focal / fwd`
- Сортировка по дальности + отрисовка от дальних к ближним
- Наложение кербов, разметки и тумана

#### Проекция
```
scale = focal / forward
screen_x = SCREEN_W / 2 + right × scale
screen_y = horizon - height × scale
```

### Оптимизация
- Обрезка полигонов вне экрана
- Кэширование нормалей и длин сегментов
- Поиск ближайшей точки с hint (окно ±8/+40)
- Surface для трассы строится один раз

## 🤝 Вклад

Pull-request'ы приветствуются! Если хотите добавить новую трассу или функцию:

1. Fork репозитория
2. Создайте ветку (`git checkout -b feature/new-track`)
3. Commit изменений (`git commit -m 'Add new track'`)
4. Push (`git push origin feature/new-track`)
5. Откройте Pull Request

### Как добавить новую трассу

Откройте `f1_racing.py`, найдите список `TRACK_DATA` и добавьте элемент:

```python
{
    "name": "Название трассы",
    "country": "🇽🇽 Страна",
    "desc": "Короткое описание",
    "points": [(x1, y1), (x2, y2), ...],  # 8-12 точек
    "width": 120,                         # ширина дороги
    "bg": (50, 90, 60),                   # цвет фона (RGB)
    "road": (75, 75, 82),                 # цвет дороги
    "laps": 3,                            # количество кругов
    "difficulty": 2,                      # 1-3
    "night": False                        # ночная?
}
```
